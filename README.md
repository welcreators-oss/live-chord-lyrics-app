# ライブコード歌詞アプリ

ライブ本番用の「コード付き歌詞表示Webアプリ」です。背景映像を流しながら歌詞とギターコードを表示し、演者・観客が一緒に見て歌えるようにします。歌詞／コードの送りはBluetoothフットペダル（LEKATO）で操作します。

## 技術構成

- ビルドツール不使用の素のHTML/CSS/JavaScript（ESモジュール）
- データはすべてIndexedDB/localStorageに端末内保存。**外部送信は一切行いません**
- OCR（Tesseract.js）は同梱せず、曲登録画面の「OCR取り込み」実行時のみjsDelivr CDNから動的読み込み（本番中は使わないため、配布サイズ削減のためあえて同梱していません。ネット環境がある場所で曲を準備してください）
- コード譜がPDFの場合はPDF.jsを同様にCDNから動的読み込みし、1ページ目を画像化してからOCRにかけます
- JSZipは `vendor/jszip.min.js` に自前ホスト（バックアップ機能の信頼性のため）
- PWA化（Service Worker）によりオフラインキャッシュ対応。新しいバージョンを公開すると、曲一覧などの管理画面は次に開いたときに自動で最新化されます。本番モード（stage.html）だけは演奏中に勝手にリロードされると困るため自動更新せず、右下に「新しいバージョンがあります」と控えめに表示するだけにしています（曲間に画面を開き直してください）

## 画面構成

| 画面 | 内容 |
|---|---|
| 曲一覧（index.html） | 曲の追加・編集画面への遷移・削除 |
| 曲編集（pages/song-edit.html） | 曲名、曲専用背景画像、ブロック（歌詞＋コード）の編集。コード譜写真からのOCR取り込み対応 |
| 共通背景（pages/backgrounds.html） | 曲別背景が未設定の曲に使われる共通背景画像セット。順番／ランダム切り替えを選択可能 |
| セットリスト（pages/setlist.html） | 複数セットリストの作成・曲順編集・「本番で使うセットリスト」の指定 |
| 本番モード（pages/stage.html） | 背景表示＋歌詞・コードの大画面表示。フットペダル／画面タップ／矢印キーでブロック送り |
| 設定・ペダル（pages/settings.html） | フットペダルの入力テスト |
| バックアップ（pages/backup.html） | 全データ（曲・画像・セットリスト・設定）のzipエクスポート／インポート |

## 曲登録の流れ

コード譜のテキスト（コード名だけの行の下に歌詞行が続く、コード譜サイトによくある形式）が手元にある場合は、それを歌詞テキスト欄にそのまま貼り付けて「歌詞をプレビューに反映」を押すのが最も確実です。コード行を自動検出し、コードの行・位置まで自動配置されます（OCRより正確です）。

```
Am7      C
やさしい光が ふりそそぐ
F      G/B
夜に 二人で歩いた道
```

テキストが手元にない場合（紙の楽譜しかない等）は以下の流れになります。

1. 曲一覧で曲名を入力して追加 → 曲編集画面へ
2. 「コード譜の写真またはPDFからOCR取り込み」で写真かPDF（1ページ目のみ）をアップロードするとテキストが自動認識される（ネット接続が必要）
3. 認識結果を確認・修正し、「歌詞をプレビューに反映」を押す
   - コード譜のレイアウト（歌詞の上にコードが浮く形）はOCRが苦手とするため、誤認識が多い場合は手直しするか、手動でコードを配置してください（下記4）
4. プレビュー上の歌詞をクリックしてコード名を入力すると、その位置にコードが配置される
   - チップをドラッグ＝位置調整
   - チップをクリック＝削除
5. 必要に応じてブロックを追加・複製・並べ替え
6. 曲専用の背景画像を登録（未設定なら共通背景が使われる）

すべての変更は操作の都度、自動的にIndexedDBへ保存されます。

## 本番モードの操作

- **フットペダル**：LEKATOペダルをモード3（Up/Dn＝矢印キー）に設定してBluetooth接続。左ペダル＝前へ、右ペダル＝次へ
- **画面タップ**：画面左半分タップ＝前へ、右半分タップ＝次へ
- **キーボード**：↑＝前へ、↓＝次へ（PC確認用）
- **スペースキー／黒画面ボタン**：黒画面のON/OFF
- **Escape**：黒画面を解除
- ブロックは曲をまたいで自動的に送られます（最後のブロックまで来たら次の曲の最初へ）
- 表示位置はリロードしても復元されます
- 二重踏み防止のデバウンス処理あり

## セットアップ

### ローカルで確認する

ブラウザのES Modules・Service Workerはローカルファイル（file://）では正しく動作しないため、簡易HTTPサーバーで開いてください。

```
python -m http.server 8000
```

その後 `http://localhost:8000/` にアクセスします。

### GitHub Pagesへのデプロイ

1. このフォルダの内容をGitHubリポジトリにpush
2. リポジトリの Settings → Pages → Source で対象ブランチ／フォルダを指定して公開
3. 公開されたURLをiPadのSafariで開く

## 制限事項・実機確認が必要な項目

以下はこのフォルダ単体では検証できないため、実機での確認が必須です。

- 実際のLEKATOペダル（Bluetooth接続）での入力
- iPad SafariでのPWA表示・プロジェクターミラーリング時の見え方
- 実際のコード譜画像を使ったOCR精度（画像の解像度・手書き／印刷等により精度が変わります）
- 長時間のオフライン安定性
